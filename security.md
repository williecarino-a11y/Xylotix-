## Security Policy

## Reporting a Vulnerability

Miimiid takes security vulnerabilities seriously.

If you discover a security vulnerability in Miimiid, please do not disclose it publicly through a GitHub issue, pull request, discussion, or other public channel.

Please report security vulnerabilities privately through the repository's available GitHub security reporting mechanism.

When reporting a vulnerability, please provide, where possible:

- A clear description of the vulnerability
- The affected component, route, or feature
- Steps to reproduce the issue
- The potential security impact
- Relevant logs, screenshots, or proof-of-concept information that can be safely shared

Please do not include passwords, API keys, database credentials, authentication tokens, or other sensitive information in the report.

## Responsible Disclosure

Please allow the Miimiid maintainers reasonable time to investigate and address a reported vulnerability before publicly disclosing technical details.

Security reports will be evaluated based on their severity, exploitability, affected functionality, and potential impact.

## Scope

Security reports may include vulnerabilities affecting:

- Authentication and account security
- Authorization and access control
- API endpoints
- Database access and data exposure
- Password and email verification
- Password reset functionality
- Session or token handling
- Server-side security
- Client-side security issues with meaningful security impact
- Exposure of application secrets or sensitive configuration

## Out of Scope

The following generally do not constitute security vulnerabilities unless they demonstrate a meaningful security impact:

- Cosmetic UI issues
- General bugs without a security impact
- Feature requests
- Performance issues
- Issues requiring unlikely or unrealistic user interaction

## Security Updates

Security fixes may be documented in the project changelog and release notes when appropriate.

Sensitive vulnerability details will not be publicly disclosed until it is reasonably safe to do so.
